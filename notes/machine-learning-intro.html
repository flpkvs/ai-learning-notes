机器学习入门

📅 2026-11-01 · ⏱ 约 10 分钟 · 🏷 入门

机器学习听起来高深，但它解决的核心问题其实很朴素：让计算机从数据中自动学习规律， 而不是靠人把规则一条条写出来。这篇笔记帮你建立整体地图。

1. 机器学习的三种范式

  • 监督学习（Supervised）：数据带有「答案」（标签），模型学习输入到输出的映射。例如：给定房屋面积预测房价、识别图片中的猫。
  • 无监督学习（Unsupervised）：数据没有标签，模型自己发现结构。例如：把用户分成若干群体（聚类）、把高维数据压缩（降维）。
  • 强化学习（Reinforcement）：智能体通过与环境交互、根据「奖励」信号试错学习。例如：下围棋、玩游戏。

2. 一个最简单的例子：线性回归

假设我们要用房屋面积预测房价，线性回归就是找一条直线 y = ax + b， 让它尽量「贴近」所有样本点。模型学习的过程，就是在不断调整 a 和 b，让预测值与真实值的差距（损失）尽可能小。 

# 用 numpy 手写一个最小二乘线性回归的雏形
import numpy as np

X = np.array([50, 80, 100, 120, 150])   # 面积（平方米）
y = np.array([200, 300, 360, 420, 500]) # 房价（万元）

# 添加偏置项，求解 X @ w ≈ y
Xb = np.column_stack([np.ones_like(X), X])
w = np.linalg.pinv(Xb) @ y
print("斜率与截距:", w)

3. 过拟合：模型「死记硬背」了

如果模型在训练集上表现极好，但在没见过的数据上表现很差，就发生了 过拟合（Overfitting）——它记住了训练数据的噪声，而不是真正的规律。 反之，如果连训练集都学不好，就是 欠拟合（Underfitting）。

4. 正则化：给模型「松绑」

应对过拟合的常用手段之一是 正则化（Regularization）， 它在损失函数里加入对模型复杂度的惩罚，迫使模型保持简单、更泛化。 常见的有 L1（倾向于让部分权重变为 0）和 L2（让权重整体变小）。

5. 训练/验证/测试：三段式划分

为了让评估更可靠，通常把数据分成三份：

  1. 训练集：用来训练模型参数；
  2. 验证集：用来调超参数、选择模型；
  3. 测试集：只在最后用一次，评估模型的真实泛化能力。

小结

建立「三种范式 → 基础模型 → 过拟合与正则化 → 数据划分」这条主线， 机器学习就不再是零散的概念堆砌。下一步可以挑一个范式，动手跑一个真实项目。
